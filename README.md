# خط‌پلی | KhatPlay

استودیوی استاتیک و آفلاین تایپوگرافی فارسی برای ساخت پست و استوری اینستاگرام. تمام ویرایش‌ها در مرورگر انجام می‌شود؛ پروژه به CDN، سرویس یا بسته‌ی runtime نیاز ندارد.

## اجرا

`index.html` را باز کنید یا از داخل همین پوشه یک سرور ساده اجرا کنید:

```sh
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. Clipboard API در بعضی مرورگرها فقط روی `localhost` یا HTTPS فعال است؛ در حالت `file://` دکمه‌ی کپی در صورت پشتیبانی‌نشدن، PNG را دانلود می‌کند.

## امکانات

- ویرایش زنده‌ی متن فارسی و ترکیبی فارسی/لاتین روی Canvas با RTL، شکست خطوط، ZWNJ و انتخاب شیوه‌ی رقم‌های فارسی، عربی یا لاتین.
- پیش‌نمایش روی استوری ۱۰۸۰×۱۹۲۰، پست عمودی ۱۰۸۰×۱۳۵۰ و پست مربعی ۱۰۸۰×۱۰۸۰؛ همراه مقصدهای حفظ‌شده‌ی استوری تلگرام، Threads و استاتوس واتساپ و حاشیه‌ی امن هر استوری.
- انتخاب خانواده و وزن، جای‌گیری خودکار یا دستی اندازه، فاصله‌ی حروف و خطوط و تراز راست/وسط/چپ.
- رنگ متن و پس‌زمینه، پس‌زمینه‌ی تک‌رنگ/گرادیانی/شفاف، سواچ‌های آماده، کنتراست خودکار، سایه و کادر متن.
- جست‌وجوی قلم، فیلتر بدنه/تیتر/دکوراتیو، نمونه‌ی مستقل هر قلم، علاقه‌مندی و مقایسه‌ی تا سه قلم.
- ۱۲ قالب آماده، ترکیب تصادفی، Undo/Redo، ذخیره‌ی خودکار آخرین طرح در `localStorage` و حالت تیره/روشن.
- خروجی PNG و JPG باکیفیت و تلاش برای کپی PNG در Clipboard.
- ده قلم محلی در شروع آماده می‌شوند تا نمونه‌ی هر کارت و پیش‌نمایش Canvas بدون hover از فونت واقعی استفاده کنند.

## پوشه‌ها

- `index.html`: رابط و ترتیب بارگذاری فایل‌ها.
- `css/app.css`: طراحی responsive و تعریف دستی `@font-face` محلی.
- `js/app.js`: state، Canvas، کنترل‌ها، history، ذخیره و export.
- `js/fonts.js`: ده قلم فعال و اطلاعات family، وزن و مسیر فایل‌ها.
- `fonts/`: فونت‌های محلی WOFF2؛ Morabba به‌دلیل پرچم no-subsetting به‌صورت فایل کامل نگه داشته شده است.
- `licenses/` و `LICENSES.md`: اسناد منبع و وضعیت بررسی مجوز.

## مجوز فونت‌ها

مالک پروژه خرید پنج قلم تازه را تأیید کرده است. فایل‌های مجوز منبع و پرچم‌های embedding/subsetting در [LICENSES.md](LICENSES.md) ثبت شده‌اند؛ پیش از انتشار یا توزیع پروژه، مجازبودن استفاده‌ی وب و تبدیل/subset را با مجوز ناشر تطبیق دهید و کدهای لایسنس خواسته‌شده را درج کنید.

## نکات مرورگر

بارگذاری فونت‌ها و ساخت تصویر بعد از بازشدن صفحه کاملاً محلی است. ذخیره‌ی خودکار و علاقه‌مندی‌ها وابسته به `localStorage` همین origin هستند. رندر متن ترکیبی و اتصال حروف به shaping مرورگر تکیه دارد؛ خروجی را در مرورگر هدف هم بازبینی کنید.
